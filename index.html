刻度尺、量筒、天平的规范使用高频考点

  • 刻度尺：先看量程、分度值、零刻线；有磨损从其他整刻度量起；读数要估读到分度值的下一位；记录必须带单位。
  • 量筒：放水平桌面，视线与凹液面最低处相平（水银则与凸面最高处相平）。俯视读数偏大、仰视读数偏小。
  • 天平：水平台 → 游码归零 → 调平衡螺母使指针居中（螺母向指针偏转的反方向调）→ 左物右码 → 由大到小加砝码 → 最后移游码。称量时不可再动平衡螺母。
易错误差不是错误，不可消除只能减小（多次测量取平均值、改用更精密仪器、改进方法）；错误可以避免。

初中必会的六种物理思想方法必背

  • 控制变量法：探究多因素问题（影响电阻的因素、压力作用效果、滑动摩擦力等）。
  • 转换法：把看不见的量转化成看得见的现象（用泡沫凹陷显示压力作用效果、用小球被撞距离显示动能大小、用温度计示数显示内能变化）。
  • 等效替代法：合力代替分力、总电阻代替各电阻、平面镜成像用等大蜡烛代替像。
  • 模型法/理想化：光线、磁感线、杠杆、匀速直线运动。
  • 类比法：电流类比水流、电压类比水压。
  • 推理法（实验+推理）：真空不能传声、牛顿第一定律。

初中 02 · 声现象

声音的产生与传播

  • 声由物体振动产生，振动停止发声停止（但声音不会立即消失）。
  • 传播需要介质，真空不能传声。传播速度：固体 > 液体 > 气体。
  • 15 ℃ 空气中 v = 340 m/s（必背）。
回声测距 s = v t / 2（t 为发出到听到回声的总时间）
易错人耳分辨原声与回声，回声至少要晚 0.1 s，对应障碍物距离至少 17 m。

乐音三要素必背

特性决定因素生活描述
音调频率（Hz），越快越高「尖细/低沉」「男低音女高音」
响度振幅，还与距离、是否分散有关「大声/小声」「引吭高歌」的"高"指响度
音色发声体的材料与结构「闻其声知其人」「听音辨西瓜生熟」
口诀音调看频率（快高慢低），响度看振幅（幅大声响），音色辨身份（谁在发声）。

人耳听觉范围 20 Hz ~ 20000 Hz；低于 20 Hz 为次声波（地震、海啸、核爆，传得远、能量强），高于 20000 Hz 为超声波（B 超、声呐、清洗、碎石、加湿器）。

声的利用与噪声控制

  • 声可以传递信息（B 超、声呐、敲瓷器听裂纹）和传递能量（超声波清洗、碎石、加湿）。
  • 噪声减弱三途径：在声源处（禁鸣、消声器）、在传播过程中（隔音墙、种树）、在人耳处（耳塞）。
  • 声音强弱等级单位 分贝 dB；0 dB 是人刚能听到的最微弱声音，为保证休息应不超 50 dB。
易错「超声波传得远」是错的——次声波才传得远、绕射能力强；超声波方向性好、穿透力强。

初中 03 · 光现象与透镜

光的直线传播

  • 光在同种、均匀介质中沿直线传播。应用：小孔成像、影子、日食月食、激光准直、射击三点一线。
  • 真空中光速 c = 3×10⁸ m/s（水中约 3/4 c，玻璃中约 2/3 c）。
  • 小孔成像：成倒立实像，可大可小；像的形状只与物体形状有关，与孔的形状无关。

光的反射与平面镜成像高频考点

反射定律 三线共面、法线居中、两角相等：∠i = ∠r（反射角 = 入射角）
  • 反射角、入射角都是与法线的夹角。光垂直入射时入射角 = 0°。
  • 镜面反射与漫反射都遵守反射定律；黑板"反光"是镜面反射，能从各角度看到物体是漫反射。
  • 平面镜成像特点：正立、等大、虚像，像与物关于镜面对称，像与物到镜面距离相等，连线与镜面垂直，左右（前后）相反。
易错①人靠近镜子，像大小不变（只是视角变大）；②像与物之间距离 = 2× 物到镜距离，人以 v 靠近镜，像与人相对速度为 2v；③平面镜转过 α，反射光线转 2α。
实验要点用玻璃板代替平面镜（便于确定像的位置）；用两支相同蜡烛（比较像与物大小）；光屏承接不到像说明是虚像；玻璃板要与桌面垂直，否则像与另一支蜡烛无法重合。

光的折射

  • 光从空气斜射入水/玻璃：折射角 小于 入射角，折射光线靠近法线；反之则远离法线。
  • 光垂直入射时传播方向不改变（折射角 = 入射角 = 0°）。
  • 折射现象：筷子"折断"、池水"变浅"、海市蜃楼、早晨看到地平线下的太阳、看水中的鱼比实际位置浅（偏高）。
口诀空气中的角总是大的：「空气角大」——不管从哪进哪出，空气一侧的角一定更大。

光的色散：白光经三棱镜分解为红橙黄绿蓝靛紫。红光偏折最小，紫光偏折最大。色光三原色 红绿蓝；颜料三原色 红黄蓝（品红、黄、青）。红外线特点是热效应强（遥控器、夜视仪、红外线测温），紫外线能使荧光物质发光、杀菌、助合成维生素D（验钞机）。

易错不透明物体的颜色由它反射的色光决定；透明物体的颜色由它透过的色光决定。红光照绿色物体，物体呈黑色。

初中 04 · 温度与物态变化

温度计的原理与使用

  • 原理：液体的热胀冷缩。摄氏温度规定：1 标准大气压下冰水混合物为 0 ℃，沸水为 100 ℃。
  • 使用：玻璃泡全部浸入被测液体、不碰容器壁和底、示数稳定后读数、读数时不取出、视线与液柱上表面相平。
  • 体温计特殊：量程 35~42 ℃，分度值 0.1 ℃，有缩口，可以离开人体读数，用前必须甩一甩。

六种物态变化必背

名称过程吸/放热常见例子
熔化固 → 液吸热冰化水、蜡烛熔化、铁水冶炼
凝固液 → 固放热水结冰、铸造成型
汽化液 → 气吸热蒸发、沸腾、酒精变干
液化气 → 液放热白气、露、雾、"出汗"的冷饮瓶、雾凇前的水汽
升华固 → 气吸热干冰升华、樟脑丸变小、冰冻衣服变干、灯丝变细
凝华气 → 固放热霜、雾凇、窗玻璃内侧冰花、灯泡内壁变黑
口诀「固液气三角，顺时针吸热（熔化—汽化—升华），逆时针放热（凝固—液化—凝华）」；凡是变成"更活跃"的状态就吸热。
易错看到的"白气"是小水珠（液化），不是水蒸气；水蒸气无色透明看不见。冬天嘴里呼出白气是液化，夏天开冰箱门冒白气也是液化。

晶体、非晶体与蒸发、沸腾

  • 晶体（冰、海波、各种金属、萘）有固定熔点，熔化时吸热但温度不变，处于固液共存态；非晶体（蜡、松香、玻璃、沥青）无熔点，边吸热边升温。
  • 晶体熔化条件：达到熔点 + 继续吸热，两者缺一不可。

易错①沸点随气压升高而升高（高压锅、高原水不到 100 ℃就开）；②沸腾时气泡上升变大，沸腾前气泡上升变小；③"水的沸点不一定是 100 ℃"。

初中 05 · 质量与密度

核心公式与物理意义

密度 ρ = m / V　　变形：m = ρV，V = m / ρ
  • 质量是物体所含物质的多少，与形状、状态、位置、温度都无关（是物体的属性）。
  • 密度是物质的特性：同种物质密度一般相同，与质量、体积无关；但与物质种类、状态、温度有关。
  • 必记：ρ水 = 1.0×10³ kg/m³ = 1 g/cm³；ρ冰 = 0.9×10³；ρ酒精 = 0.8×10³；ρ水银 = 13.6×10³；ρ铁/钢 ≈ 7.9×10³；ρ铝 = 2.7×10³；ρ铜 = 8.9×10³；空气 ≈ 1.29 kg/m³。
易错水结成冰：质量不变、密度变小、体积变大（水结冰体积增大 1/9，冰化水体积减少 1/10）。水在 4 ℃ 时密度最大，这是"反常膨胀"。

测密度的实验方法高频考点

固体（不吸水、密度大于水）：① 天平测 m；② 量筒装适量水记 V₁；③ 用细线拴住浸没记 V₂；④ ρ = m/(V₂−V₁)。
液体（减少误差的正确顺序）：① 测烧杯 + 液体总质量 m₁；② 倒部分入量筒测体积 V；③ 测剩余烧杯 + 液体质量 m₂；④ ρ = (m₁−m₂)/V。

为什么这样排序如果先测空杯质量、再全部倒入量筒，杯壁残留液体会让测得体积偏小 → 密度偏大。上面的"倒出法"避开了残留误差。
易错①测固体先测质量后测体积（沾水会使质量偏大）；②物体放入量筒不能有气泡；③"密度偏大/偏小"分析永远回到 ρ = m/V，看分子分母各自偏大还是偏小。

密度的应用与常见题型

  • 鉴别物质：算出 ρ 查表。判断空心实心：三法——比密度、比体积、比质量。
  • 空心体积：V空 = V总 − m/ρ。
  • 混合密度：ρ = (m₁+m₂)/(V₁+V₂)，不能直接把密度取平均。

初中 06 · 力、运动和力

力的基本概念

  • 力是物体对物体的作用，力不能脱离物体单独存在，一定有施力物体和受力物体。
  • 力的作用是相互的：作用力与反作用力大小相等、方向相反、作用在两个不同物体上。
  • 力的作用效果：改变物体的形状、改变物体的运动状态（速度大小或方向改变）。
  • 力的三要素：大小、方向、作用点，用力的示意图表示。

重力、弹力、摩擦力必背

重力 G = m g，g = 9.8 N/kg（粗略计算取 10 N/kg），方向竖直向下，作用点在重心
  • 弹力：发生弹性形变的物体要恢复原状而产生的力（支持力、压力、拉力都是弹力）。弹簧测力计原理：在弹性限度内，弹簧伸长量与所受拉力成正比。
  • 滑动摩擦力大小与压力大小和接触面粗糙程度有关，与接触面积、速度无关。
  • 摩擦力方向：与物体相对运动（或相对运动趋势）方向相反，不一定与运动方向相反（如传送带上加速的货物）。
  • 增大摩擦：增大压力、增大粗糙度、变滚动为滑动；减小摩擦：减小压力、变光滑、变滑动为滚动、加润滑油、使接触面分离（气垫、磁悬浮）。
测滑动摩擦力实验必须让木块做匀速直线运动，此时二力平衡 f = F拉。改进方案：固定木块、拉动下面的长木板，此时不必匀速，读数也更稳定。
易错静止的物体也可能受摩擦力（静摩擦）；静摩擦力大小由平衡条件决定，与压力无关。手握瓶子越用力，静摩擦力不变（等于重力）。

牛顿第一定律与二力平衡压轴常考

牛顿第一定律（惯性定律） 一切物体在没有受到力的作用时，总保持静止状态或匀速直线运动状态。
  • 该定律是在实验基础上通过推理得出的，不能直接由实验验证。
  • 惯性是物体保持运动状态不变的性质，一切物体都有惯性，惯性只与质量有关，与速度、受力无关。惯性不是力，不能说"受到惯性"或"惯性作用"。
  • 二力平衡条件：同物、等大、反向、共线（作用在同一物体、大小相等、方向相反、作用在同一直线上）。
  • 物体处于平衡状态（静止或匀速直线运动）⟺ 受平衡力（或不受力）。
比较平衡力相互作用力
受力物体同一个物体两个物体
能否单独存在可以（撤一个另一个仍在）不能，同生同灭
力的性质可以不同一定相同
口诀平衡力"一物二力四同条"；相互作用力"你推我我推你，二物之间同时起"。

运动的描述

速度 v = s / t；平均速度 v̄ = s总 / t总（不能对速度取平均）

运动和静止是相对的，判断运动必须先选参照物；被选作参照物的物体默认是静止的。

易错全程平均速度 ≠ (v₁+v₂)/2。前后半程速度分别 v₁、v₂ 时，全程平均速度 = 2v₁v₂/(v₁+v₂)。

初中 07 · 压强

固体压强

压强 p = F / S（F 是垂直作用在表面的压力，S 是受力面积，单位 m²）
  • 压强表示压力的作用效果。增大压强：增大压力或减小受力面积（刀刃、针尖）；减小压强：减小压力或增大受力面积（书包宽带、履带、地基）。
  • 放在水平面上的物体：F = G = mg；对直柱形（柱体、长方体、圆柱）固体还有 p = ρgh（h 为柱体高度）。
易错①压力≠重力，只有放在水平面上且无其他外力时才相等；②S 是接触面积，不是物体底面积（如砖只放一半在桌上）；③单位必须用 m²，1 cm² = 10⁻⁴ m²。

液体压强必背

液体压强 p = ρ g h（h 是该点到自由液面的竖直深度）
  • 液体内部向各个方向都有压强；同一深度各方向压强相等；深度越深压强越大；同深度下液体密度越大压强越大。
  • 液体压强只与 ρ 和 h 有关，与容器形状、液体总重、总体积无关。
  • 连通器：不流动的同种液体，各容器中液面总保持相平。应用：茶壶、船闸、锅炉水位计、下水道 U 形管。
易错先算 p 再算 F（F = pS）适用于液体对容器底的压力；容器对桌面的压力才用 F = G总。上宽下窄的容器中，液体对底部压力 小于 液重；上窄下宽则大于液重。

大气压强与流体压强

  • 托里拆利实验测出标准大气压 = 760 mm 水银柱 = 1.013×10⁵ Pa（约能托起 10.3 m 高的水柱）。
  • 托里拆利实验中：玻璃管倾斜、变粗变细、上提下压，水银柱竖直高度不变；管内混入空气则高度变小；换成水则需 10 m 以上的管。
  • 大气压随海拔升高而减小；沸点随气压增大而升高。
  • 流体压强与流速：流速越大的位置，压强越小。应用：飞机机翼（上凸下平，上方流速大压强小 → 向上升力）、火车站安全线、两船并行相吸、吹纸条上飘。
口诀「深水压强大，流快压强小」。

初中 08 · 浮力初中最难

四种求浮力的方法必背

方法公式适用条件
称重法F浮 = G − F示已知空气中和液体中的弹簧测力计读数
压力差法F浮 = F向上 − F向下浮力的本质来源；解释"贴底物体不受浮力"
阿基米德原理F浮 = G排 = ρ液 g V排万能，一切浸在液体或气体中的物体
漂浮/悬浮法F浮 = G物 = m物 g仅当物体漂浮或悬浮时
易错浮力只与 ρ液 和 V排 有关，与物体密度、形状、深度、是否运动都无关。物体完全浸没后继续下沉，浮力不变。

物体的浮沉条件

状态力的关系密度关系V排 与 V物
上浮 → 漂浮F浮 > G → 静止时 F浮 = Gρ物 < ρ液V排 < V物
悬浮F浮 = Gρ物 = ρ液V排 = V物
下沉 → 沉底F浮 < G（沉底后 F浮+F支 = G）ρ物 > ρ液V排 = V物
漂浮黄金公式 ρ物V物 = ρ液V排 ⟹ V排/V物 = ρ物/ρ液
典型结论①冰漂在水中，冰化后液面不变；冰中含石块，化后液面下降；冰中含木块或气泡，化后液面不变；②同一物体在不同液体中漂浮，浮力都等于重力，浮力相同，密度大的液体里露出得多；③轮船从河驶入海，浮力不变（都等于重力），排水体积变小，船身上浮一些。

浮力应用与综合计算

  • 轮船：空心增大 V排；排水量指满载时排开水的质量，m排 = m船 + m货。
  • 潜水艇：靠改变自身重力（充/排水）实现浮沉，浮力不变。
  • 气球飞艇：充密度小于空气的气体，靠改变浮力（体积）或放气实现升降。
  • 密度计：在各种液体中都漂浮，浮力等于自重始终不变，液体密度越大浸入越浅，刻度上小下大、不均匀。
解题模板浮力大题先判断状态（漂/悬/沉），再选公式：漂浮悬浮优先用 F浮=G；沉底优先用 F浮=ρ液gV物；有弹簧测力计就用称重法；最后用受力平衡列方程。

初中 09 · 功、功率、机械能

功与功率

功 W = F s（s 是在力的方向上移动的距离），单位 J
功率 P = W / t = F v（v 为匀速运动速度），单位 W

做功的两个必要条件：① 有力作用在物体上；② 物体在力的方向上移动了距离。

三种不做功情形①有力无距离（推没推动的墙）；②有距离无力（惯性滑行）；③力与运动方向垂直（提着水桶水平走，重力不做功）。
口诀「劳而无功、不劳无功、垂直无功」。

机械能

  • 动能 Ek：与质量和速度有关，速度影响更大。
  • 重力势能 Ep：与质量和被举高的高度有关。
  • 弹性势能：与弹性形变程度有关。
  • 机械能 = 动能 + 势能。只有动能与势能相互转化时，机械能守恒；有摩擦或空气阻力时机械能减少（转化为内能）。
易错"匀速下降的降落伞"：动能不变、重力势能减小 → 机械能减小；"匀速上升的气球"：动能不变、势能增大 → 机械能增大；"沿光滑斜面下滑"：机械能守恒。

初中 11 · 内能、比热容与热机

分子动理论与内能

  • 物质由分子、原子构成；分子在永不停息地做无规则运动（扩散现象证明，温度越高扩散越快）；分子间存在相互作用的引力和斥力。
  • 内能：物体内所有分子热运动的动能与分子势能的总和。一切物体在任何温度下都有内能。
  • 改变内能的两种方式：做功（能的形式转化）和热传递（能的转移），二者等效。
  • 热传递的条件是存在温度差，传递的是热量（过程量，不能说"含有热量"）。
易错①温度升高内能一定增大，但内能增大温度不一定升高（晶体熔化、水沸腾）；②热量、功是过程量，只能说"吸收/放出、做了多少"；内能、温度是状态量。

比热容与热量计算必背

吸放热 Q吸 = c m (t − t₀) = c m Δt；Q放 = c m (t₀ − t)
燃料放热 Q放 = m q（固/液燃料）；Q放 = V q（气体燃料，q 单位 J/m³）
  • c水 = 4.2×10³ J/(kg·℃)——所有常见物质中最大（必背）。
  • 比热容是物质的特性，与质量、温度变化、吸放热多少无关，但与状态有关（冰 ≈ 2.1×10³）。
  • 水比热大的应用：暖气用水、汽车水冷、沿海昼夜温差小、稻田夜间灌水防冻。
  • 热值 q 是燃料的特性，与是否完全燃烧、燃烧多少无关。
热平衡不计热损失时 Q吸 = Q放，末温相同（介于两个初温之间）。

热机与能量守恒

  • 四冲程内燃机：吸气 → 压缩（机械能→内能）→ 做功（内能→机械能）→ 排气。一个工作循环有四个冲程、活塞往返 2 次、曲轴飞轮转 2 圈、对外做功 1 次。
  • 汽油机用火花塞点燃，柴油机用喷油嘴压燃（压缩比大、效率高、马力大）。
热机效率 η = W有用 / Q放 × 100% = W / (mq)

能量既不会凭空消失，也不会凭空产生，只会从一种形式转化为另一种形式，或从一个物体转移到另一个物体，总量保持不变——能量守恒定律。因此永动机不可能制成。

易错热机效率永远小于 100%，主要损失在废气带走的内能；提高效率的办法是使燃料充分燃烧、减少摩擦、利用废气余热。

初中 12 · 电流、电压、电阻与电路

电路基础

  • 电荷：同种电荷相互排斥，异种电荷相互吸引。摩擦起电的实质是电子的转移（得电子带负电，失电子带正电），不是创造电荷。
  • 电流方向规定为正电荷定向移动的方向；金属导体中自由电子定向移动方向与电流方向相反。电源外部电流从正极流向负极。
  • 电路三种状态：通路、断路（开路）、短路。电源短路非常危险（电流极大）；用电器短路则该用电器不工作、其他仍工作。
串联并联
电流I = I₁ = I₂（处处相等）I = I₁ + I₂
电压U = U₁ + U₂U = U₁ = U₂
电阻R = R₁ + R₂（比任一个都大）1/R = 1/R₁ + 1/R₂（比任一个都小）
分配关系分压：U₁/U₂ = R₁/R₂分流：I₁/I₂ = R₂/R₁
特点一断全断，开关控制整个电路互不影响，干路开关控总
并联电阻速算两个电阻并联：R = R₁R₂/(R₁+R₂)（"积除以和"）；n 个相同电阻 R₀ 并联：R = R₀/n。

电阻

电阻 R 是导体本身的性质，由材料、长度、横截面积决定，还与温度有关（金属温度升高电阻变大）；与电压、电流无关。
同种材料：越长电阻越大，越粗电阻越小。半导体、超导、热敏/光敏电阻是常考应用。

初中 13 · 欧姆定律与电功率

欧姆定律必背

欧姆定律 I = U / R　变形 U = I R，R = U / I（R 只是计算式，不表示 R 与 U、I 有关）
动态电路分析三步法①先判断电路连接方式、电表测什么；②由滑片移动判断某电阻的变化 → 总电阻变化 → 干路电流变化；③按"定值电阻两端电压随其电流同向变化"逐个推导。
串联口诀：「串联电路，谁大谁分压」；并联口诀：「并联电路，谁小谁分流」。

电功、电功率与焦耳定律必背

电功 W = U I t = P t；纯电阻还可用 W = I²Rt = U²t/R
电功率 P = W / t = U I；纯电阻还可用 P = I²R = U²/R
焦耳定律 Q = I² R t（普遍适用）；纯电阻电路中 Q = W
  • 额定功率是在额定电压下工作的功率（铭牌值，唯一确定）；实际功率随实际电压变化：P实/P额 = (U实/U额)²。
  • 电能表读数：相邻两次读数相减，单位 kW·h（度）。1 kW·h = 3.6×10⁶ J。"3000 r/(kW·h)" 表示每消耗 1 kW·h 电能转盘转 3000 圈。
易错①P = U²/R 和 P = I²R 只适用于纯电阻（电动机、日光灯不是纯电阻，只能用 P = UI）；②电动机 W电 = UIt，其中发热 Q = I²Rt，机械功 W机 = UIt − I²Rt；③"灯泡亮度看实际功率"，不看额定功率。
测小灯泡电功率实验器材：电源、开关、滑动变阻器、电流表、电压表、小灯泡、导线。步骤：连接（开关断开、滑片阻值最大）→ 调节滑片使电压表示数为额定电压 → 读电流 → P = UI。灯丝电阻随温度升高而增大，所以不同电压下算出的 R 不同，不能求平均值。

生活用电

  • 家庭电路电压 220 V，人体安全电压不高于 36 V。
  • 组成：进户线（火线 + 零线）→ 电能表 → 总开关 → 保险装置 → 各用电器并联。
  • 火线与零线间电压 220 V，火线与地间 220 V，零线与地间 0 V。用试电笔辨别火线时手必须接触笔尾金属体，且不能碰笔尖金属体。
  • 三孔插座接地线，把用电器金属外壳接地防触电。开关必须接在火线与用电器之间。
  • 电路中电流过大的两个原因：短路和用电器总功率过大。
易错触电类型：单线触电（碰火线且站地上）、双线触电（同时碰火线零线）。鸟站在一根电线上不触电，因为两脚间电压极小。

安全用电必背

  • 安全用电原则：不接触低压带电体，不靠近高压带电体（高压电弧触电、跨步电压触电不需要直接接触）。
  • 雷电是自然界剧烈的放电现象，高大建筑物要安装避雷针（尖端放电原理，通过接地线把电荷导入大地）。
  • 保险丝由电阻率大、熔点低的铅锑合金制成，电流过大时因发热熔断自动切断电路；不能用铜丝、铁丝代替。现多用空气开关（断路器）。
  • 漏电保护器：当火线中电流与零线中电流不相等（有电流经人体或外壳流入大地）时迅速切断电路。
  • 常见违规行为：湿手触碰开关插座、在电线上晾衣物、用绝缘层破损的导线、同一插线板接过多大功率用电器、发现有人触电直接用手拉。
  • 正确处置触电：先切断电源或用干燥的木棒挑开电线，再施救；电器着火先断电，不能直接泼水。
口诀「低压不接触，高压不靠近；湿手不碰电，断电再施救。」

磁现象与磁场

  • 磁体两端磁性最强处叫磁极；同名磁极相斥，异名磁极相吸。

  • 地磁场：地理北极附近是地磁南极（S），所以指南针 N 极指北。我国宋代沈括发现磁偏角。

高中 01 · 运动的描述与匀变速直线运动

基本概念辨析

  • 质点：物体的形状大小对研究问题影响可忽略时的理想模型。与物体大小无关，与研究问题有关。
  • 位移是矢量（初位置指向末位置的有向线段），路程是标量。只有单向直线运动时位移大小才等于路程。
  • 平均速度 v̄ = Δx/Δt（矢量），平均速率 = 路程/时间（标量），两者一般不等。
  • 瞬时速度是 Δt → 0 时的极限。加速度 a = Δv/Δt，描述速度变化快慢，方向与 Δv 同向。
易错①a 很大不代表 v 大（如刚发射的火箭 v=0 而 a 大）；②a 与 v 同向则加速，反向则减速，与 a 增大或减小无关；③a 减小但与 v 同向时，物体仍在加速，只是加速得越来越慢。

高中 02 · 相互作用——力与平衡

三种常见力

胡克定律 F = k x（x 为形变量，k 为劲度系数，单位 N/m）
滑动摩擦力 f = μ FN（μ 为动摩擦因数，FN 为正压力，不一定等于重力）
  • 静摩擦力大小由平衡方程或牛顿第二定律决定，范围 0 < f ≤ fmax，方向与相对运动趋势相反。
  • 弹力方向：面接触垂直于接触面；点面接触垂直于面；绳的拉力沿绳背离物体；轻杆的力方向不一定沿杆。
  • 轻绳/轻杆/轻弹簧：绳与接触面的弹力可以突变（瞬时消失），弹簧和橡皮条的弹力不能突变——这是"瞬时性问题"的关键。

力的合成与分解必背

  • 遵循平行四边形定则（矢量运算法则），也可用三角形定则。
  • 两个分力 F₁、F₂ 的合力范围：|F₁ − F₂| ≤ F ≤ F₁ + F₂。夹角越大合力越小。
  • 互相垂直时 F = √(F₁² + F₂²)，tanθ = F₂/F₁。
  • 两个等大的力 F 夹角 θ 时，合力 F合 = 2F cos(θ/2)。夹角 120° 时合力等于 F。
正交分解建系原则：让尽可能多的力落在坐标轴上。斜面问题通常沿斜面和垂直斜面建系。列式：ΣFx = 0，ΣFy = 0（平衡）或 ΣF = ma（沿 a 方向）。
三力平衡的三个结论①三力必共点且合力为零，任意两力的合力与第三个力等大反向；②三个力矢量首尾相接构成闭合三角形；③动态平衡问题：一力恒定、一力方向不变、第三力方向变化 → 用矢量三角形（相似三角形法）判断变化趋势。

高中 03 · 牛顿运动定律

三大定律必背

牛顿第一定律 一切物体总保持匀速直线运动或静止状态，直到有外力迫使它改变这种状态。（揭示了力是改变运动状态的原因，惯性的量度是质量）
牛顿第二定律 F合 = m a——瞬时性、矢量性、同体性、独立性
牛顿第三定律 作用力与反作用力等大、反向、共线、异体、同性质、同时产生同时消失
易错牛顿第二定律中的 F 是合外力；a 与 F合 始终同向且瞬时对应（合力为零则 a 立即为零）。牛顿定律只适用于惯性参考系、宏观低速物体。

两类基本问题与解题模板

  • 已知力求运动：受力分析 → 求 F合 → a = F合/m → 代入运动学公式。
  • 已知运动求力：运动学公式求 a → F合 = ma → 结合受力分析求未知力。
  • 桥梁是加速度 a。这是高中力学最核心的一句话。
整体法与隔离法求系统外力或共同加速度用整体法；求系统内部相互作用力用隔离法（隔离受力少的物体更简便）。两者常配合使用。

超重与失重易混

状态加速度方向视重典型情形
超重向上FN = m(g+a) > mg电梯加速上升 / 减速下降
失重向下FN = m(g−a) < mg电梯加速下降 / 减速上升
完全失重向下且 a = gFN = 0自由落体、绕地飞行的空间站
易错超重失重时物体的重力不变，改变的是对支持面的压力（视重）。判断只看加速度方向，与速度方向无关。完全失重时一切与重力有关的现象消失（水不流出、天平失效、浮力为零）。

三大经典模型压轴常考

① 连接体（含绳、杆、接触）

光滑水平面上 F 推 m₁、m₂（相接触），整体 a = F/(m₁+m₂)，隔离得相互作用力 F12 = m₂F/(m₁+m₂)——结论：接触面上的相互作用力 = 外力 × (被推物体质量 / 系统总质量)，从另一侧施力时结论对调，所以务必隔离"被推的那个物体"来算。

② 传送带模型

关键判断：物体与带的相对滑动方向决定摩擦力方向；当二者速度相等时是转折点，之后要重新判断能否共速（看静摩擦是否够，水平带上共速后一起匀速；倾斜带要比较 μ 与 tanθ）。

③ 滑块—木板（板块）模型

先判断两者是否共速运动（用整体法算 a共，再隔离检验所需摩擦力是否超过最大静摩擦）。若发生相对滑动，分别列牛二方程，注意位移关系：相对位移 Δs = s₁ − s₂ = 板长（恰好滑出）。

临界与极值常见临界词：「恰好」「最大/最小」「刚好不滑动」「刚要离开」。对应条件：绳恰好拉直 T = 0；恰好不滑动 f = fmax = μFN；刚离开地面 FN = 0；速度相等。

实验：探究加速度与力、质量的关系

  • 方法：控制变量法；用钩码（或砂桶）重力近似代替小车所受拉力。
  • 必须平衡摩擦力：将木板一端垫高，不挂钩码时轻推小车能在纸带上打出间隔均匀的点。换用不同质量的小车时不需要重新平衡。
  • 近似条件：钩码总质量 m 远小于小车质量 M（否则图像末端向下弯曲）。
  • 图像处理：作 a−F 图（正比直线）和 a−1/M 图（正比直线），不作 a−M 图（双曲线难判断）。
图像异常分析a−F 图不过原点且在 F 轴有正截距 → 没平衡摩擦力或平衡不足；在 a 轴有正截距 → 平衡摩擦力过度（木板垫得太高）。

高中 04 · 曲线运动、平抛与圆周运动

曲线运动的条件与运动的合成分解

  • 曲线运动的速度方向沿该点切线方向；做曲线运动的条件是合外力方向与速度方向不在同一直线上。
  • 合力（加速度）总指向轨迹的凹侧。
  • 运动的合成与分解遵循平行四边形定则，分运动具有独立性、等时性、同时性。
  • 小船渡河：① 渡河时间最短 → 船头垂直河岸，t = d/v船；② 位移最短（v船 > v水）→ 让合速度垂直河岸，船头偏向上游，使 v船sinθ = v水，此时最短位移即河宽 d；③ 若 v船 < v水，最短位移 d·v水/v船。
  • 绳（杆）末端速度分解：把实际速度分解为沿绳方向（拉绳速度）和垂直绳方向（转动速度），沿绳分量相等是关键。

平抛运动必背

水平 x = v₀ t，vx = v₀（匀速）　　竖直 y = ½ g t²，vy = g t（自由落体）
合速度 v = √(v₀² + g²t²)；速度偏角 tanθ = vy/v₀ = gt/v₀；位移偏角 tanα = y/x = gt/(2v₀)
黄金结论tanθ = 2 tanα——速度偏角的正切是位移偏角正切的 2 倍。且任意时刻速度的反向延长线过水平位移的中点。
  • 落地时间只由下落高度决定：t = √(2h/g)，与初速度无关。
  • 射程 x = v₀√(2h/g)。
  • 斜面上的平抛：落在斜面上 → 位移方向沿斜面（用位移分解，tanα = y/x）；垂直打在斜面上 → 速度方向垂直斜面（用速度分解）；离斜面最远 → 垂直斜面方向速度为零。

斜抛运动

以速度 v₀ 与水平方向成 θ 角抛出，只受重力。可分解为：水平方向匀速直线运动（vx = v₀cosθ）+ 竖直方向竖直上抛运动（初速 v₀sinθ，加速度 −g）。

飞行时间 t = 2v₀sinθ/g　　最大高度 h = v₀²sin²θ/(2g)　　水平射程 x = v₀²sin2θ/g
  • θ = 45° 时射程最大（同一 v₀，不计阻力）；互余的两个抛射角（如 30° 和 60°）射程相同。
  • 最高点速度不为零，v = v₀cosθ（只剩水平分量），加速度仍为 g。
  • 轨迹关于最高点对称：上升与下落时间相等，同一高度速度大小相等、与水平方向夹角相等。
易错斜抛在最高点不是速度为零（区别于竖直上抛），也不是加速度为零；全程加速度恒为 g，是匀变速曲线运动。

圆周运动的物理量关系必背

高中 05 · 万有引力与航天

开普勒定律与万有引力定律必背

  • 开普勒第一定律（轨道）：行星绕太阳沿椭圆轨道运行，太阳在椭圆的一个焦点上。
  • 开普勒第二定律（面积）：行星与太阳连线在相等时间内扫过相等面积 ⟹ 近日点速度快，远日点速度慢。
  • 开普勒第三定律（周期）：a³ / T² = k（k 只与中心天体有关）。
万有引力定律 F = G m₁ m₂ / r²，G = 6.67×10⁻¹¹ N·m²/kg²（卡文迪什用扭秤测出）

两大黄金替代式解题核心

黄金代换（地表） 忽略自转时 GM = g R²（重力等于万有引力）——已知 g 和 R 就能算 GM。
环绕方程 GMm/r² = m v²/r = m ω² r = m (4π²/T²) r = m an——一切卫星问题的起点。
由此得： v = √(GM/r)，ω = √(GM/r³)，T = 2π√(r³/GM)，an = GM/r²
口诀「越高越慢」：轨道半径 r 越大，v、ω、a 越小，只有周期 T 越大。
估算天体质量与密度①已知卫星 r、T：M = 4π²r³/(GT²)；②已知 g、R：M = gR²/G；③密度 ρ = 3πr³/(GT²R³)，若卫星贴近表面（r = R）则 ρ = 3π/(GT²)。

三个宇宙速度与同步卫星

名称数值含义
第一宇宙速度7.9 km/s最大环绕速度 = 最小发射速度，v = √(gR) = √(GM/R)
第二宇宙速度11.2 km/s脱离地球引力（逃逸速度）
第三宇宙速度16.7 km/s挣脱太阳引力飞出太阳系

地球同步卫星"五个一定"：周期一定（T = 24 h）、角速度一定、高度一定（h ≈ 3.6×10⁴ km）、速率一定（约 3.1 km/s）、必须在赤道正上方且与地球自转同向。

易错①卫星的变轨：加速 → 做离心运动升到高轨道（高轨道上速度反而更小）；减速 → 落入低轨道。②卫星内的物体处于完全失重，但仍受万有引力（它正好提供向心力）。③近地卫星速度 7.9 km/s 是环绕速度的最大值。

卫星变轨与双星模型压轴常考

① 卫星变轨（霍曼转移）

  • 低圆轨道 Ⅰ → 椭圆转移轨道 Ⅱ → 高圆轨道 Ⅲ：在近地点 P 点火加速进入椭圆轨道，在远地点 Q 再次点火加速进入高圆轨道（返回则两次减速）。
  • 同一点比速度：vⅢ(Q) > vⅡ(Q)，vⅡ(P) > vⅠ(P)——外轨道在切点处需要更大速度。
  • 同一点比加速度：同一位置万有引力相同，故加速度相同（与轨道无关）。
  • 比周期：由开普勒第三定律，半长轴越大周期越大，TⅠ < TⅡ < TⅢ。
  • 椭圆轨道上机械能守恒：近地点速度大、势能小；远地点速度小、势能大。变轨点火瞬间机械能改变。

② 双星模型

两星绕连线上某点（质心）转动：角速度 ω、周期 T 相同；Gm₁m₂/L² = m₁ω²r₁ = m₂ω²r₂
  • 轨道半径与质量成反比：m₁r₁ = m₂r₂，且 r₁ + r₂ = L（L 为两星间距，万有引力中用 L，向心力中用各自的 r）。
  • 总质量 m₁ + m₂ = 4π²L³/(GT²)——已知 L、T 可求双星总质量。
  • 三星、四星模型：对某一颗星受力分析，合力指向圆心提供向心力，注意引力来自其他每颗星的矢量和。
易错双星问题中最易错的是把万有引力写成 Gm₁m₂/r₁²——分母必须是两星距离 L 的平方，不是轨道半径。

高中 06 · 功、能与机械能守恒

功与功率必背

恒力做功 W = F s cosα（α 为力与位移的夹角）
  • α < 90° 做正功；α = 90° 不做功；α > 90° 做负功（即克服该力做功）。功是标量但有正负。
  • 总功可用 W合 = F合·s·cosα，也可用各力做功的代数和。
平均功率 P̄ = W/t；瞬时功率 P = F v cosα
机车启动两模型①恒定功率启动：a 逐渐减小，v 增大，做变加速运动，最终 vmax = P/f（此时 a = 0）；②恒定牵引力（匀加速）启动：先匀加速到 P额 对应速度 v₁ = P额/F，之后变为恒功率运动，最终仍达 vmax = P额/f。两种方式的 vmax 相同。

动能定理最有力的工具

动能 Ek = ½ m v²　　动能定理 W合 = ΔEk = ½mv² − ½mv₀²
为什么优先用动能定理①它是标量方程，不涉及方向；②对变力做功、曲线运动、多过程同样适用；③只关心初末状态，不管中间细节。凡是"求速度、求位移、求摩擦力做功、求变力功"的题，先想动能定理。

重力做功、势能与机械能守恒

  • 重力做功 WG = mgh（h 为下降高度），只与初末位置有关，与路径无关。
  • 重力势能 Ep = m g h（相对参考面，可正可负）。WG = −ΔEp。
  • 弹性势能 Ep = ½kx²（选修/竞赛，高考多用"弹簧形变量相同则弹性势能相同"这一结论）。
机械能守恒条件：只有重力（和弹力）做功，或其他力做功的代数和为零。
Ek1 + Ep1 = Ek2 + Ep2，也可写作 ΔEk增 = ΔEp减
易错①有摩擦、有介质阻力、有电流做功时机械能不守恒；②"绳突然绷直"、"完全非弹性碰撞"会损失机械能；③判断守恒看做功情况，不看速度是否变化；④系统机械能守恒时可能有个体不守恒。

功能关系总表必背

做功对应能量变化
合外力做功 W合= 动能变化 ΔEk
重力做功 WG= −重力势能变化（WG = −ΔEp）
弹簧弹力做功= −弹性势能变化
除重力弹力外其他力做的功 W其他= 机械能的变化 ΔE
克服滑动摩擦力做的功（相对滑动）Q = f · Δs相对 = 系统增加的内能
电场力做功= −电势能变化
安培力做功 / 克服安培力做功= 电能减少 / 增加
摩擦生热的黄金公式 Q = f · Δs相对——注意用相对位移（如板块模型中的相对滑动距离），而不是对地位移。

高中 07 · 静电场

库仑定律与电场强度必背

库仑定律 F = k q₁ q₂ / r²，k = 9.0×10⁹ N·m²/C²（适用于真空中的点电荷）
电场强度（定义式）E = F / q　单位 N/C = V/m，方向与正电荷受力方向相同
点电荷场强 E = k Q / r²（决定式）　匀强电场 E = U / d（d 为沿场强方向的距离）
易错E = F/q 是定义式，E 由场源和位置决定，与试探电荷 q 是否存在无关；E = kQ/r² 只适用于点电荷；E = U/d 只适用于匀强电场。
  • 电场线特点：起于正电荷（或无穷远）止于负电荷（或无穷远）；不相交、不闭合；疏密表示场强大小；切线方向为该点场强方向；电场线不是带电粒子的运动轨迹。
  • 元电荷 e = 1.6×10⁻¹⁹ C，任何带电体电荷量都是 e 的整数倍。

电势、电势能与电势差

电势能 Ep = q φ　电势 φ = Ep/q（标量，有正负，与零势点选取有关）
电势差 UAB = φA − φB　电场力做功 WAB = q UAB = − ΔEp
三条判断口诀①沿电场线方向电势降低（一定降低，且降得最快）；②正电荷在电势高处电势能大，负电荷在电势低处电势能大；③电场力做正功 ⟹ 电势能减小（与重力做功和重力势能的关系完全类似）。
  • 等势面：与电场线处处垂直，沿等势面移动电荷电场力不做功；导体表面和内部是等势体。等势面越密电场越强。
  • 静电平衡：导体内部场强处处为 0，净电荷只分布在外表面（越尖锐处电荷密度越大 → 尖端放电）；静电屏蔽由此而来。
易错①电势 φ、电势能 Ep、电势差 U 都是标量，代入时要带正负号；②E 为零处 φ 不一定为零（等量同种电荷连线中点），φ 为零处 E 不一定为零（等量异种电荷中垂面）。

带电粒子在电场中的运动压轴常考

① 加速（沿电场线方向）

q U = ½ m v² − ½ m v₀²；若初速为零 v = √(2qU/m)

② 偏转（类平抛）

沿初速方向 L = v₀ t；垂直方向 a = qU/(m d)，y = ½ a t² = qUL²/(2mdv₀²)
偏转角 tanθ = vy/v₀ = qUL/(mdv₀²)；出场后沿直线，反向延长线过板长中点
重要结论若粒子先经 U₁ 加速再经偏转电压 U₂ 偏转，则 y = U₂L²/(4U₁d)，与粒子的电荷量和质量都无关——这就是示波器能同时偏转不同粒子的原因。
解题提示①在电场中一般忽略重力（基本粒子如电子、质子），但带电微粒、油滴、小球通常要考虑重力，题目会明示；②处理复杂路径优先用动能定理 qU + W其他 = ΔEk。

电容器

电容定义 C = Q / U（单位 F，1 F = 10⁶ μF = 10¹² pF）
平行板电容 C = εS / (4πkd)——与正对面积成正比，与板间距成反比，与介电常数成正比
两类动态分析
电容器接在电源上（U 不变）：d 增大 → C 减小 → Q 减小 → E = U/d 减小。
电容器充电后断开电源（Q 不变）：d 增大 → C 减小 → U 增大 → E = Q/(εS·常数) 不变（场强与 d 无关）。

静电感应、静电平衡与静电的利用防止

  • 三种起电方式：摩擦起电（电子转移）、接触起电（电荷再分配，相同金属球接触后平分）、感应起电（导体靠近带电体，近端感应出异号电荷，远端同号；先接地再移走手指可使导体带上与带电体异号的净电荷）。三种方式的本质都是电荷转移，遵守电荷守恒定律。
  • 静电平衡的特征（必背四条）：①导体内部合场强处处为 0（外场与感应电荷的场叠加抵消）；②导体是等势体，表面是等势面；③电场线与导体表面垂直；④净电荷只分布在外表面，表面越尖锐电荷密度越大。
  • 尖端放电：尖端处场强大，使附近空气电离而放电 → 避雷针。
  • 静电屏蔽：金属壳（网）内部不受外电场影响 → 电学仪器金属罩、高压带电作业服、汽车内躲避雷电。
  • 静电的利用：静电除尘、静电喷漆、静电复印；静电的防止：油罐车拖地铁链、飞机轮胎用导电橡胶、印刷厂保持空气湿润。
易错感应起电时导体总电荷不变（除非接地）；"近异远同"只对感应电荷分布而言。验电器金属箔张开只说明带了电，不能直接判断电性。

高中 08 · 恒定电流与闭合电路

基本公式必背

电流 I = q / t = n e S v（微观表达式，n 为单位体积自由电荷数，v 为定向移动速率）
欧姆定律 I = U/R　电阻定律 R = ρ L / S（ρ 为电阻率，由材料和温度决定）
电功 W = U I t　电热 Q = I² R t　电功率 P = U I　纯电阻时 P = I²R = U²/R
易错非纯电阻（电动机、电解槽）只能用 W = UIt 和 Q = I²Rt，不能用 U²/R。电动机的机械功率 P机 = UI − I²r。

闭合电路欧姆定律核心

E = I (R + r)　　U外 = E − I r　　U内 = I r
功率关系 总功率 P总 = E I；输出功率 P出 = U I = I²R；内耗 P内 = I²r；效率 η = U/E = R/(R+r)
输出功率最大条件当 R = r 时，输出功率取最大值 Pmax = E²/(4r)。但此时效率只有 50%——最大功率与最高效率不能兼得。
闭合电路动态分析（"串反并同"）某一电阻 R 增大 → 总电阻增大 → 干路电流 I 减小 → 路端电压 U = E − Ir 增大 → 与之串联的电阻分压减小（变化"相反"），与之并联的支路电压增大（变化"相同"）。
更稳妥的方法："局部 → 整体 → 局部" 三步走。

电表改装与测量实验实验必考

  • 电流计 G（内阻 Rg，满偏电流 Ig）改装：
    改电流表——并联小电阻分流 R并 = IgRg/(I − Ig)；
    改电压表——串联大电阻分压 R串 = U/Ig − Rg。
选择方案适用误差
电流表内外接安培计外接（电压表并在 R 上）小电阻（R ≪ RV）电压表分流 → R 测偏小
安培计内接大电阻（R ≫ RA）电流表分压 → R 测偏大
滑动变阻器接法分压式（并联接法）要求电压从零开始连续可调、R滑 远小于 R—
限流式（串联接法）电路简单省电，调节范围要求不高—
口诀「大内偏大，小外偏小」——测大电阻用安培计内接，结果偏大；测小电阻用外接，结果偏小。判据：Rx 与 √(RARV) 比较，大于则内接。
测电源电动势和内阻用 U−I 图像：纵截距 = E，斜率绝对值 = r。系统误差：由于电压表分流，E 和 r 的测量值都偏小。

高中 09 · 动量与动量守恒

动量、冲量与动量定理必背

动量 p = m v（矢量，方向与 v 相同，单位 kg·m/s）　冲量 I = F t（矢量，单位 N·s）
动量定理 I合 = Δp = m v₂ − m v₁
  • 动量定理是矢量式，一维问题必须先规定正方向再代入正负号。
  • 适用于变力（此时 F 为平均力）和短时作用（碰撞、打击、爆炸）。
  • 重要关系：Ek = p²/(2m)，p = √(2mEk)。
生活应用缓冲装置（安全气囊、跳高垫、玻璃用泡沫包装）都是通过延长作用时间来减小作用力，Δp 不变而 F = Δp/t 变小。

动量守恒定律高考必考

守恒条件：系统不受外力，或所受外力矢量和为零。
近似条件：内力远大于外力（碰撞、爆炸）；分方向条件：某方向合外力为零则该方向动量守恒。
m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′　（一维取正方向后代数运算）
碰撞类型动量动能特征
弹性碰撞守恒守恒无机械能损失
非弹性碰撞守恒减少一般情形
完全非弹性碰撞守恒损失最大碰后共速 v = (m₁v₁+m₂v₂)/(m₁+m₂)
一维弹性碰撞公式（m₂ 静止）
v₁′ = (m₁−m₂)v₁/(m₁+m₂)　　v₂′ = 2m₁v₁/(m₁+m₂)
特例：m₁ = m₂ 时交换速度（v₁′=0，v₂′=v₁）；m₁ ≫ m₂ 时 v₁′≈v₁、v₂′≈2v₁；m₁ ≪ m₂ 时 v₁′≈−v₁（原速弹回）。
碰撞合理性三判据①动量守恒；②动能不增加（Ek后 ≤ Ek前）；③符合实际——碰前后位置关系合理（后面的追上前面的要求 v后 > v前；碰后前面的速度不小于后面的）。

典型模型

  • 子弹打木块：动量守恒求共速；能量：Q = f·d相对 = ΔEk损失。
  • 人船模型：系统初动量为零 ⟹ m₁s₁ = m₂s₂，且 s₁ + s₂ = L（相对位移）。
  • 爆炸/反冲：动量守恒，动能增加（化学能转化）。火箭是反冲的应用。
  • "滑块+弧形槽"：水平方向动量守恒 + 系统机械能守恒，联立求解，等价于弹性碰撞。

高中 10 · 机械振动与机械波

简谐运动

动力学定义 F = − k x（回复力与位移大小成正比、方向相反）；a = − kx/m
运动学表达 x = A sin(ωt + φ)，ω = 2π/T = 2πf
  • 振幅 A 表征能量（与周期无关）；周期 T 只由振动系统本身决定（固有周期）。
  • 在平衡位置：位移 0、回复力 0、加速度 0、速度最大、动能最大。
    在最大位移处：位移最大、回复力最大、加速度最大、速度为零、势能最大。
  • 简谐运动中机械能守恒，动能与势能周期性相互转化（转化周期为 T/2）。
单摆周期（θ < 5°）T = 2π √(L/g)——与摆球质量、振幅无关，L 为摆长（悬点到球心）
弹簧振子周期 T = 2π √(m/k)
用单摆测重力加速度 g = 4π²L/T²。误差分析：把摆线长当摆长 → L 偏小 → g 偏小；把摆长多算了一个直径 → g 偏大；把 n 次全振动数成 n+1 次 → T 偏小 → g 偏大。计时应从最低点开始。

受迫振动与共振：受迫振动的频率等于驱动力频率，与固有频率无关；当驱动力频率 = 固有频率时振幅最大，即共振（共振曲线的峰值）。

机械波易错点密集

波速公式 v = λ f = λ / T　（v 由介质决定，f 由波源决定）
  • 波传播的是振动形式和能量，介质质点只在平衡位置附近振动，不随波迁移。
  • 横波（振动方向 ⊥ 传播方向，有波峰波谷，如绳波、电磁波、地震S波）；纵波（振动方向 ∥ 传播方向，有疏密部，如声波、地震P波）。
  • 判断质点振动方向：「同侧法」——沿波传播方向，质点沿波形曲线向"波来的方向"看；或用"上下坡法"：沿波传播方向看波形，处于上坡的质点向下振动，下坡的质点向上振动。
  • 经过 nT 波形复原；经 T/2 波形反相。波形平移距离 Δx = v·Δt。
多解问题①波传播方向未知 → 两个方向都要讨论；②时间 Δt 与周期关系未给 → Δt = nT + t′；③波长与距离关系未给 → Δx = nλ + x′。答案通常带 n = 0,1,2,…。
波的干涉条件：两列波频率相同（相位差恒定）。加强点：路程差 Δr = nλ；减弱点：Δr = (2n+1)λ/2。加强点始终加强（振幅 A₁+A₂），但位移仍随时间变化，也会经过零点。
波的衍射：当缝、孔或障碍物尺寸与波长相差不多或更小时，衍射现象明显。
多普勒效应：波源与观察者相互靠近时接收频率变高，远离时变低；波源频率本身不变。

高中 11 · 磁场与磁场对电流、电荷的作用

磁感应强度与磁通量

磁感应强度 B = F / (I L)（当导线与 B 垂直时），单位特斯拉 T，1 T = 1 N/(A·m)
磁通量 Φ = B S（S 为垂直于 B 的有效面积），单位韦伯 Wb；B = Φ/S 也叫磁通密度
常见磁场的方向判断（安培定则 / 右手螺旋）
①直线电流：右手大拇指指电流，四指环绕方向即磁感线方向；
②环形电流 / 通电螺线管：右手四指指电流，大拇指指 N 极（管内磁感线方向）。

安培力与洛伦兹力必背

安培力 F = B I L sinθ（θ 为 B 与 I 的夹角；I ∥ B 时 F = 0）
洛伦兹力 F = q v B sinθ（v ∥ B 时 F = 0）
左手定则让磁感线穿入手心，四指指电流方向（或正电荷运动方向），大拇指所指即为安培力/洛伦兹力方向。负电荷要把四指指向其运动的反方向。
易错洛伦兹力永远不做功（F ⊥ v），只改变速度方向不改变速率；但安培力可以做功（宏观上是大量洛伦兹力的合效果）。

带电粒子在匀强磁场中的圆周运动压轴常考

q v B = m v² / r ⟹ 半径 r = m v / (q B)　周期 T = 2πm/(qB)（与 v、r 无关）
圆心角与时间 t = (θ/2π) T = θm/(qB)
画圆三步法①定圆心：过入射点作 v 的垂线，圆心必在这条垂线上（用左手定则定出偏转侧）；②定半径：用几何关系（弦长、垂径定理、相似）或 r = mv/(qB)；③定圆心角：弦切角 = 圆心角的一半，或利用"进出磁场速度偏转角 = 圆心角"。
  • 速度选择器：E 与 B 正交，只有 v = E/B 的粒子才能直线通过（与电荷量、正负、质量都无关）。
  • 质谱仪：先加速 qU = ½mv²，再垂直进入磁场，r = (1/B)√(2mU/q)，据 r 分辨同位素。
  • 回旋加速器：交变电压频率必须等于粒子回旋频率 f = qB/(2πm)；最大动能 Ekm = q²B²R²/(2m)，只由 B 和最大半径 R 决定，与加速电压无关（加速电压只影响加速次数）。
  • 霍尔效应：UH = k I B / d，用于测磁感应强度、判断载流子的正负。
多解与临界①未说明电荷正负 → 两种偏转方向；②"恰好不射出磁场" → 轨迹与边界相切；③"从边界某点射出" → 用几何作图找最大/最小半径；④粒子源向各方向发射 → 用"旋转圆"方法找边界。

带电粒子在复合场中的运动压轴常考

组合场：粒子先后经过不同区域的场（先电场加速、再磁场偏转）——分段处理，每段用各自规律，衔接点速度是桥梁。
复合场（叠加场）：同一区域同时存在电场、磁场（可能还有重力）——整体受力分析，判断运动类型。

复合场中的三种典型运动

  • 匀速直线运动：合力为零。常见"电磁三力平衡"：重力 mg、电场力 qE、洛伦兹力 qvB 三力平衡（洛伦兹力方向垂直于 v，注意用左手定则核对方向可行性）。
  • 匀速圆周运动：若 qE = mg（电场力恰好平衡重力），剩下洛伦兹力提供向心力 → 做匀速圆周运动，r = mv/(qB)。这是"重力不可忽略"型压轴题的标志性设定。
  • 较复杂曲线运动：合力大小方向都变化时，不能用运动学公式，改用动能定理 / 能量守恒（洛伦兹力不做功，只需算重力与电场力的功）。
解题总纲①受力分析（重力要不要计？题目说"微粒、液滴、小球"通常要计；"电子、质子、离子"通常不计）；②判断运动类型（直线 / 圆周 / 一般曲线）；③直线用平衡或牛顿定律，圆周用半径周期公式 + 几何关系，一般曲线用动能定理。
易错①洛伦兹力随速度变化，速度反向则洛伦兹力也反向；②电场反向粒子受力反向，但磁场反向不影响洛伦兹力大小只影响方向；③在复合场中"做匀速圆周运动"是重要隐含条件 ⟹ 必有 qE = mg。

高中 12 · 电磁感应

楞次定律与右手定则核心

产生感应电流的条件：闭合回路的磁通量发生变化（不是"有磁通量"，也不一定要切割）。

楞次定律感应电流的磁场总要阻碍引起感应电流的磁通量的变化。
四种"阻碍"的表现：①增反减同（磁通量增加则反向，减少则同向）；②来拒去留（相对运动）；③增缩减扩（回路面积）；④阻碍相对运动。

右手定则（专用于切割磁感线）：让磁感线穿入手心，大拇指指导体运动方向，四指指向即感应电流方向。

法拉第电磁感应定律必背

通式 E = n ΔΦ / Δt（求平均电动势；ΔΦ/Δt 是 Φ−t 图的斜率）
切割式 E = B L v sinθ（求瞬时电动势；L 为有效长度，即导体在垂直于 v 和 B 方向上的投影长度）
转动式（棒绕一端在垂直磁场平面内转动）E = ½ B L² ω
自感电动势 E = L ΔI/Δt；线圈磁场能 E = ½ L I²
易错①ΔΦ/Δt 是磁通量的变化率，Φ 大不代表 E 大，Φ = 0 时 E 可以最大；②E = BLv 中 v 必须与 B 垂直分量对应；③电路中的路端电压 U = E − Ir，安培力用 F = BIL。

② 力：安培力 F = BIL = B²L²v/(R+r)，方向总是阻碍相对运动，代入牛顿第二定律；
③ 能：克服安培力做的功 = 回路产生的电能；Q = I²Rt 或由能量守恒 W其他 − ΔEk − ΔEp = Q。
  • 棒达最大速度（收尾速度）：a = 0，此时 mg sinθ = B²L²vm/(R+r)（斜面）或 F外 = B²L²vm/(R+r)。

高中 13 · 交变电流与电磁波

正弦交流电必背

有效值（方均根） U = Um/√2 ≈ 0.707 Um，I = Im/√2（仅适用于正弦交流电）

  • 我国市电：频率 50 Hz，周期 0.02 s，有效值 220 V，峰值约 311 V。

变压器动态分析的因果链「电压看匝数，功率看负载，电流由功率定」：
U₂ 由 U₁ 和匝数比唯一决定 → 负载 R 变化改变 I₂ → P₂ 变化 → P₁ 随之变化 → I₁ 变化。原线圈电流是"果"不是"因"。

高中 14 · 热学——分子动理论、气体与热力学定律

分子动理论

  • 物质由大量分子组成；分子在永不停息地做无规则热运动；分子间同时存在引力和斥力。
  • 阿伏加德罗常数 NA = 6.02×10²³ mol⁻¹——微观与宏观的桥梁。
    分子数 N = n NA = (m/M) NA = (V/Vmol) NA。
  • 分子直径数量级 10⁻¹⁰ m；分子质量数量级 10⁻²⁶ kg。
  • 布朗运动是悬浮微粒的运动（不是分子运动），它间接反映液体分子的无规则运动。温度越高、颗粒越小，布朗运动越剧烈。
分子力与分子势能随 r 的变化令 r₀ ≈ 10⁻¹⁰ m 为平衡距离：
r < r₀：斥力 > 引力，合力表现为斥力，r 减小时分子势能增大；
r = r₀：合力为零，分子势能最小；
r > r₀：引力 > 斥力，合力表现为引力，r 增大时分子势能增大；
r > 10 r₀：分子力可忽略。
易错①分子力随 r 增大先增大后减小（斥力和引力都随 r 增大而减小，但斥力减小得更快）；②温度是分子平均动能的标志，温度相同时不同气体分子的平均动能相同，但由于质量不同，平均速率不同；③气体内能 = 分子平均动能 × 分子数（理想气体不计分子势能），所以理想气体内能只由温度和分子数（物质的量）决定。

气体实验定律与理想气体状态方程必背

定律条件表达式图像特征

热力学定律

热力学第一定律 ΔU = W + Q
符号取正（+）取负（−）
W外界对气体做功（压缩）气体对外做功（膨胀）
Q气体吸热气体放热
ΔU内能增加（理想气体即温度升高）内能减少
常见特例①等温：ΔU = 0 ⟹ Q = −W（吸热等于对外做功）；②绝热：Q = 0 ⟹ ΔU = W（绝热压缩升温、绝热膨胀降温）；③等容：W = 0 ⟹ ΔU = Q；④气体向真空自由膨胀：W = 0、Q = 0 ⟹ 温度不变。

热力学第二定律（两种表述）：克劳修斯表述——热量不能自发地从低温物体传到高温物体；开尔文表述——不可能从单一热源吸热并把它全部用来做功而不产生其他影响。本质是一切与热现象有关的宏观过程都具有方向性（不可逆），微观上是熵增（分子运动无序程度增加）。
推论：第一类永动机违反能量守恒（热一律），第二类永动机违反热二律。

固体、液体与物态变化

  • 晶体有确定熔点，单晶体各向异性、多晶体各向同性；非晶体无固定熔点、各向同性。同种物质可能既有晶体又有非晶体形态（如石英与玻璃）。
  • 液体表面张力使液面有收缩到最小面积的趋势（露珠呈球形、硬币上水面凸起）。
  • 浸润与不浸润 → 毛细现象（浸润液体在细管中上升，不浸润则下降）。
  • 饱和汽压只与温度有关（同种液体），与体积无关；相对湿度 = 实际水汽压 / 同温度饱和汽压 × 100%。
  • 液晶兼有液体的流动性和晶体的各向异性。

高中 15 · 几何光学与光的波动性

折射定律与全反射必背

折射定律 n = sin θ₁ / sin θ₂（θ₁ 为真空/空气中的角）
折射率与光速 n = c / v　⟹　介质中光速 v = c/n，波长 λ介 = λ₀/n（频率不变）
全反射 条件：光从光密介质射向光疏介质 且 入射角 ≥ 临界角 C；sin C = 1/n
  • 应用：光导纤维（内芯折射率大）、全反射棱镜、海市蜃楼、水中气泡看起来发亮。
  • 同一介质中，紫光折射率最大 → 速度最小、临界角最小、偏折最大；红光相反。
记忆链频率从红到紫依次增大：折射率 n 增大 → 介质中 v 减小 → 临界角 C 减小 → 偏折更厉害 → 波长更短 → 光子能量 E = hν 更大 → 衍射/干涉条纹间距更小。

光的干涉、衍射与偏振

双缝干涉条纹间距 Δy = L λ / d（L 为双缝到屏距离，d 为双缝间距）
  • 亮条纹条件：光程差 Δr = k λ（k = 0,1,2…）；暗条纹：Δr = (2k+1) λ/2。
  • 薄膜干涉（增透膜、检查平面平整度、肥皂膜彩色条纹）：由薄膜前后两个表面反射的光叠加形成。增透膜厚度为 λ/4（膜中波长）。
  • 衍射：单缝越窄条纹越宽；泊松亮斑（圆盘衍射中心亮点）是衍射的著名证据。
  • 偏振证明光是横波；自然光通过偏振片后成为偏振光；反射光、散射光是部分偏振光（拍照/开车用偏振镜消反光）。
干涉 vs 衍射双缝干涉条纹等间距、明暗相间、亮度相同；单缝衍射条纹不等间距（中央最宽最亮，两侧渐窄渐暗）。

相对论初步

  • 狭义相对论两条基本假设（爱因斯坦，1905）：①相对性原理——在一切惯性系中物理规律都相同；②光速不变原理——真空中光速在任何惯性系中都是 c，与光源和观察者的运动无关。
  • 时间延缓（动钟变慢）：Δt = Δt₀ / √(1 − v²/c²)——运动的钟走得慢（μ 子寿命延长是实验证据）。
  • 长度收缩（动尺变短）：L = L₀ √(1 − v²/c²)——沿运动方向的长度缩短，垂直方向不变。
  • 质速关系：速度越大质量越大，任何有静质量的物体不可能达到光速；质能方程 E = mc² 是相对论的重要结论。
  • v ≪ c 时相对论效应可忽略，回到经典力学——经典力学是相对论的低速近似。
  • 广义相对论（了解）：引力使时间变慢、光线弯曲（星光经过太阳附近偏折已被观测证实）、引力波（2016 年 LIGO 直接探测到）。
易错"动钟变慢、动尺变短"是相对效应，互相观察对方都变慢/变短，不是钟表机械故障或测量误差；GPS 卫星必须同时修正狭义（速度）与广义（引力）相对论效应才能准确定位。

专题 03 · 高中必考实验（电学）

伏安法：内接还是外接？必背

安培计内接（电流表靠近待测电阻）安培计外接（电压表直接并在 R 上）
误差来源电流表分压，U 测偏大电压表分流，I 测偏大
测量结果R测 = R + RA 偏大R测 = R∥RV 偏小
适用大电阻（R ≫ RA）小电阻（R ≪ RV）
口诀「大内偏大，小外偏小」——大电阻内接、测量值偏大；小电阻外接、测量值偏小。
判断方法：比较 R 与 √(RARV)，大则内接，小则外接；或用"试触法"看两表读数变化率。

滑动变阻器两种接法

  • 限流接法：串联在电路中。简单省电，但调节范围小。能用限流优先限流。
  • 分压接法：变阻器全部接入，负载接在滑片与一端之间。电压可从 0 调起。必须分压的三种情况：①要求电压从零开始连续调节（描伏安特性曲线）；②负载电阻远大于变阻器总阻值；③限流时电流仍超过量程或器材额定值。

测电源电动势与内阻实验必考

闭合电路欧姆定律 U = E − I r → 作 U–I 图：纵截距 = E，斜率的绝对值 = r
  • 改变滑动变阻器阻值，测多组 (I, U)，描点作图（图像法优于解方程组：能减小偶然误差、剔除坏点）。
  • 系统误差（电压表分流方案）：测得 E测 略小于真实值，r测 略小于真实值（r测 = r∥RV 的效果）。
  • 作图注意：坐标轴可以不从零开始（放大有效区间），但此时纵截距要按坐标读，不能想当然。

半偏法与电表改装

① 半偏法测电流表内阻

  • 电路：电源 + 大阻值变阻器 R（串）+ 待测电流表 + 可并联的电阻箱 R′。
  • 步骤:先断开 R′，调 R 使电流表满偏；再并入电阻箱 R′，保持 R 不变，调 R′ 使电流表半偏 → 此时 Rg ≈ R′。
  • 成立条件与误差：要求 R ≫ Rg（并入 R′ 后干路电流近似不变）；实际干路电流略增大，流过 R′ 的电流大于半偏值 → Rg测 = R′ 偏小。

② 电表改装必背

改大量程电流表：并联分流电阻 R并 = IgRg / (I − Ig)　　改电压表：串联分压电阻 R串 = U/Ig − Rg
口诀「改流并小，改压串大」——改大电流量程并联小电阻，改电压表串联大电阻。

其他电学实验要点

  • 测金属丝电阻率：螺旋测微器测直径 d（不同位置测三次取平均）、刻度尺测接入电路部分长度 L，伏安法测 R，ρ = πd²R/(4L)。金属丝电阻小 → 安培计外接。
  • 描绘小灯泡伏安特性曲线：电压要求从零调起 → 滑动变阻器分压接法；灯丝温度升高电阻增大 → I–U 图线斜率逐渐减小（向 U 轴弯曲）。
  • 练习使用多用电表（欧姆挡）：机械调零 → 选挡 → 红黑表笔短接欧姆调零（换挡后必须重新调零）→ 测量（指针在中间刻度附近最准，偏角太大换小倍率挡）→ 读数 × 倍率 → 用毕拨到 OFF 或交流电压最高挡。红表笔接表内电源负极（电流从黑表笔流出），判断二极管正负极时注意。
  • 测电池电动势内阻/描伏安曲线时的电表选择：读数超过量程 1/3、指针偏转尽量大；不确定时先用大量程试触。

受力分析进阶技巧

  • 整体法与隔离法：求外力（地面支持力、摩擦力）用整体法；求系统内力（绳张力、相互压力）必须隔离。加速度相同的连接体优先整体求 a，再隔离求内力。
  • 摩擦角：全反力（支持力与摩擦力的合力）与法线的最大夹角 φ 满足 tanφ = μ。物体在斜面上恰好不下滑 ⟺ 斜面倾角 θ = φ ⟺ tanθ = μ。"无论 F 多大都推不动" ⟺ 推力方向与法线夹角小于摩擦角。
  • 三力平衡的图解法（动态平衡）：一个力恒定、一个力方向不变、第三个力方向变化时，画矢量三角形随动分析；第三个力最小值出现在它与"方向不变的力"垂直时。
  • 正交分解方向选取：一般沿加速度方向和垂直方向建轴；斜面问题沿斜面/垂直斜面分解重力：沿面 mgsinθ、垂直面 mgcosθ。

临界与极值问题

  • 常见临界词及隐含条件：「恰好滑动」→ f = μN（静摩擦达最大）；「恰好离开接触面」→ N = 0；「绳恰好绷直」→ T = 0；「恰好通过最高点」→（绳/内轨）mg = mv²/r；「恰好不相对滑动」→ 共同加速度且静摩擦达最大；「恰好到达某点」→ 该点速度为零（或最小速度）。
  • 追及问题临界：速度相等是距离最大/最小、能否追上的分界点。
  • 极值方法：函数法（二次函数顶点）、三角函数合成 asinθ + bcosθ = √(a²+b²) sin(θ+φ)、图解法（矢量三角形）、不等式法。

常用解题策略清单考前必看

  • 选规律的优先级（力学综合题）：①只问初末速度/位移 → 动能定理；②碰撞、爆炸、反冲 → 动量守恒；③只有重力弹力做功 → 机械能守恒；④求时间或涉及过程细节 → 牛顿定律 + 运动学；⑤变力冲量、流体连续作用 → 动量定理。
  • 多过程问题：画运动示意图分段，标出每段的初末速度衔接量；能量类多过程可对全程用一次动能定理。
  • 估算题：抓数量级，常用近似 g ≈ 10 m/s²，一层楼 ≈ 3 m，步行 ≈ 1 m/s，人的质量 ≈ 50~60 kg。
  • 单位制检验：算完看单位量纲是否正确，是排查公式错误最快的手段。
  • 对称性与逆向思维：末速度为零的匀减速 → 倒过来当初速度为零的匀加速处理（刹车问题先判断停止时间）。

高频易错清单考前必看

  • 矢量运算先定正方向：动量、冲量、位移、速度、加速度都要带正负号。
  • 单位统一到国际单位制再代入：cm² → m²，g/cm³ → kg/m³，km/h → m/s，℃ → K。
  • 「恰好」「最大/最小」「刚好」= 临界条件，必须单独列临界方程。
  • 圆周运动、电磁场问题先判断方向再算大小；多解题要讨论电荷正负、波的传播方向、时间与周期关系。
  • 非纯电阻电路不能用 P = U²/R；理想气体温度必须用开尔文；机械能守恒要先验证条件。
  • 图像题先看清坐标轴代表什么，再判断斜率、面积、截距的物理意义。
  • 实验题注意：控制变量、多次测量、系统误差方向、图像为什么这样处理。
