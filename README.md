# 物理知识大合集 · 初中 + 高中

一个**单文件、零依赖、可离线**的物理知识速查网页。打开 `index.html` 即可使用，不需要联网、不需要构建、不需要任何框架。

## 内容范围

| 分册 | 章节 |
| --- | --- |
| 初中物理 | 测量与方法、声、光与透镜、物态变化、质量与密度、力与运动、压强、浮力、功与机械能、简单机械与机械效率、内能与热机、电路、欧姆定律与电功率、电与磁 |
| 高中必修一 | 运动的描述与匀变速直线运动、相互作用与平衡、牛顿运动定律 |
| 高中必修二 | 曲线运动与平抛圆周、万有引力与航天、功能关系与机械能守恒 |
| 高中必修三 | 静电场、恒定电流与闭合电路 |
| 选择性必修一 | 动量与动量守恒、机械振动与机械波 |
| 选择性必修二 | 磁场、电磁感应、交变电流与电磁波 |
| 选择性必修三 | 热学、几何光学与光的波动性、近代物理 |
| 专题突破 | 初中重点实验、高中力学实验、高中电学实验、解题方法与技巧 |
| 速查附录 | 常用常数与单位、全部核心公式一览、必背结论与口诀总汇 |

每个知识块按四类颜色分层：

- 蓝色 —— 核心公式
- 橙色 —— 易错提醒
- 绿色 —— 记忆口诀
- 粉色 —— 必背核心结论

标签含义：`必背` 需要硬记，`高频考点` / `压轴常考` 是刷题重点，其余理解即可。

## 功能

- **全文搜索**：输入关键词后自动展开并高亮命中的知识块，并显示命中数量。试试搜「口诀」「临界」「易错」「实验」，可以横向串起各章的同类知识。
- **两级目录导航**：左侧按分册分组，滚动时自动高亮当前章节。
- **章节折叠**：点击章节标题折叠 / 展开，也可一键全部展开或收起。
- **深色模式**：首次打开会跟随系统设置，也可手动切换。
- **移动端适配**：手机与平板的竖屏、横屏均已适配。窄屏下侧栏变为抽屉（点顶栏 ☰、从屏幕左边缘右滑均可打开，点遮罩、左滑或按 Esc 关闭），顶部常驻搜索框，表格可横向滑动，并已处理刘海屏安全区域。
- **打印友好**：`Ctrl/Cmd + P` 时自动展开全部内容并隐藏导航，可直接打印或存为 PDF。

## 本地使用

直接双击 `index.html`，或：

```bash
git clone https://github.com/<你的用户名>/physics-notes.git
cd physics-notes
open index.html          # macOS
```

## 在线访问

启用 GitHub Pages 后访问：`https://<你的用户名>.github.io/physics-notes/`
